Meowsic 🎵🐱

A self-initiated music website project created to explore creative UI/UX, interactive web experiences, and front-end development through a playful cat-themed music concept.

📌 Project Overview

Meowsic is a self-initiated web project that combines music and playful visual design into a single interactive experience.

The project was created as a personal experiment rather than for a client, giving me the freedom to develop the concept, branding, interface, and interactions from the ground up.

The goal was to explore how a music-focused website could feel more fun, expressive, and visually engaging while remaining easy to navigate.

🎯 Project Goals

The project was created to:

Experiment with creative UI/UX
Explore music-focused web interfaces
Practice interactive front-end development
Develop a unique visual identity
Experiment with playful web interactions
Combine illustration, branding, and web development
💡 The Concept

Meowsic combines two things: cats and music.

The concept uses a playful cat-themed identity to create a less conventional music experience.

Instead of following the visual style of a traditional music platform, the project explores how personality and visual storytelling can be incorporated into the interface.

✨ Key Features
🎵 Music-focused Interface

The website is structured around a music browsing and listening experience.

🐱 Cat-themed Visual Identity

The interface incorporates a playful cat-inspired aesthetic throughout the experience.

🎨 Custom UI/UX

The layout and visual direction were designed from scratch specifically for the project.

🖱️ Interactive Elements

Interactive components help make the experience feel more like an application rather than a static webpage.

📱 Responsive Design

The interface is designed to adapt to different screen sizes.
